# 飞书知识库同步（KnowledgeMesh → 飞书）

把 **文档型知识库** 的左侧文件夹、右侧目录与文档，**手动一键发布**到飞书 Wiki。  
KnowledgeMesh 是唯一内容源；飞书侧只托管同步结果，**不会回写**。

> 反向（飞书 → KnowledgeMesh）请用「数据源」导入，见 [数据源导入开发文档](./数据源导入开发文档.md)。

---

## 同步后长什么样

```
<知识库名称>                 ← 托管首页（标题 = 知识库名称）
├── 公共知识
│   └── 一级/二级标签
│       └── 右侧文档目录（可多层）
│           └── 文档页（原文件 + 可检索正文）
├── 未分类
├── <其它非公共一级标签>
└── _已归档                  ← KnowledgeMesh 删除后的文档会移入此处
```

每次同步：预览影响 → 确认入队 → 可看进度条。无定时、无 Webhook。

---

## 管理员：打开功能

1. 配置 `SYSTEM_AES_KEY`（32 字节，加密 App Secret）
2. 开启：

```bash
ENABLE_FEISHU_KNOWLEDGE_SYNC=true
```

`.env` / Docker Compose / Helm 均可。关闭开关**不会**删除飞书上已有页面。

## 准备飞书应用（一次性）

需要：**企业/组织账号**（个人号不行）、开放平台建应用权限、目标知识空间成员管理权限。

### 1. 创建企业自建应用

**页面：** [飞书开放平台](https://open.feishu.cn/app) → 开发者后台

1. **创建企业自建应用**（不要选商店应用 / 智能体模板）
2. 打开 **凭证与基础信息**：
   - 复制 **App ID**（`cli_xxxxxxxx`）
   - 复制 **App Secret**（点眼睛查看明文）

Secret 不会在 KnowledgeMesh 接口回显；保存后前端只显示「已配置」。请勿提交到 Git 或公开渠道。

### 2. 开通权限（应用身份）

**页面：** 应用详情 → **权限管理** → 开通权限  

权限说明：[Wiki 概览](https://open.feishu.cn/document/server-docs/docs/wiki-v2/wiki-overview)

| 权限 | 用途 |
|------|------|
| `wiki:wiki` | 知识空间 / 节点 |
| `wiki:node:create` | 创建 Wiki 节点 |
| `docx:document` | 编辑新版文档 |
| `drive:file` | 上传/下载文件 |
| `docs:document.media:upload` | 上传图片与附件 |

开通后必须 **创建版本并发布**，否则线上不生效。

### 3. 发布应用

**页面：** 应用详情 → **版本管理与发布**

**创建版本** → 保存 → **确认发布**。顶部状态应为 **已启用**。

### 4. 开通机器人能力

**页面：** 应用详情 → **添加应用能力** → **机器人** → 再发一版  

未开通时，知识空间成员搜索框通常搜不到应用名。

### 5. 把应用加入目标知识空间（必做）

**页面：** 飞书 → 目标知识空间 → **设置 → 成员设置**

1. **添加管理员**（或可编辑成员）
2. 搜索应用名 → 勾选 → 发送  

**备选：** 建群 → 加应用为群机器人 → 成员设置里搜该群并添加。

只「添加文档应用」到单个页面，**不足以**列出知识空间。

## 在 KnowledgeMesh 里同步

1. 打开文档型知识库 → **设置** → **同步飞书**
2. 填写 App ID / App Secret（填完会**自动加载**知识空间；失败点「重试」）
3. 选目标空间与位置（可根目录）→ **预览并同步** → 确认入队
4. 绑定后默认只显示状态与 **立即同步**；改凭据点 **更改配置**
5. 运行中可看进度；成功后可 **在飞书中打开**；失败可在明细里 **重试失败项**

### 规则摘要

| 点 | 说明 |
|----|------|
| 触发方式 | 仅手动；全局「保存设置」不会持久化飞书草稿 |
| 冲突 | 以 KnowledgeMesh 为准覆盖飞书托管标题/位置/内容 |
| 删除 | 权威删除后移入 `_已归档`（不永久删飞书页） |
| 空间锁定 | 首次成功后锁定；换空间需先解除绑定 |
| 回环防护 | 若已配置指向同一飞书空间的拉取数据源，会拒绝发布 |
| 可搜性 | 飞书搜索 / 问答为最终一致，成功后可能稍后才可搜 |

- [ ] `ENABLE_FEISHU_KNOWLEDGE_SYNC=true`
- [ ] `SYSTEM_AES_KEY` 已配置
- [ ] 应用状态「已启用」，权限已发布
- [ ] 应用已加入目标知识空间成员

- [ ] 飞书树为：知识库名 → 公共知识 / 未分类 / 标签 → 目录 → 文档

## 常见问题

**空间列表为空？**  
机器人能力未开通/未发布，或应用未加入知识空间成员。

**部分成功 / 超大文件？**  
单项失败不影响其它项；打开失败明细 → **重试失败项**（会跳过已成功项）。  
单文件软上限当前为 **2GB**（流式分片上传，>20MB 走飞书 multipart）；超过上限或飞书租户配额拒绝的知识会跳过/失败——请压缩/拆分后重新上传再同步。

**首页还叫 `KnowledgeMesh · xxxx`？**  
再同步一次会改成知识库名称，并把旧拍平节点挪到正确父级。
