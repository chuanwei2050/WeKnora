# 智信测评知识平台 V1.0 发布定版说明

- 对外产品版本：V1.0
- 软件包语义化版本：1.0.0
- 定版日期：2026年9月14日
- 产品名称：智信测评知识平台

## 版本展示规则

- 登录页显示“智信测评知识平台 V1.0”。
- 系统设置中的系统信息页由后端版本接口显示“V1.0”。
- 软件著作权用户手册、申请表和源程序鉴别材料页眉统一显示对应软件全称及“V1.0”。
- 前端、结构化查询服务和文档解析服务的包管理元数据使用语义化版本 `1.0.0`，与对外版本 V1.0 对应。
- Lite 安装包默认读取仓库根目录 `VERSION`，产物名称包含 `V1.0`。

## 正式构建与留档

正式提交或交付前应从本定版代码重新构建，不得复用旧版产物。构建完成后保存：

1. 安装包完整文件名、文件大小和 SHA-256。
2. 构建日期、提交哈希和构建人员。
3. 登录页与系统信息页的 V1.0 截图。
4. 四套源程序鉴别材料的文件目录、导出日期和 SHA-256。

Linux Lite 包可运行：

```bash
./scripts/package-lite.sh
```

默认产物名称形如：

```text
WeKnora-lite_V1.0_<操作系统>_<架构>.tar.gz
```

Helm／离线镜像包须在 V1.0 镜像完成构建并取得真实摘要后更新镜像标签和 digest；不得把旧镜像摘要直接标记为 V1.0。
