# ASR/TTS 能力清单

本清单用于模型配置、能力预检和私有化验收。语音能力默认关闭；不满足实时能力时必须回退到临时批量转写或纯文本路径。

## ASR

- 协议：OpenAI-compatible `POST /v1/audio/transcriptions`，或实现 `StreamingASR`/`StreamingSessionFactory`。
- 必需输入：受支持的音频 MIME 类型、模型名称、语言（可选）。
- 批量能力：`Transcribe(ctx, audioBytes, fileName)` 返回最终文本和可选时间片段。
- 实时能力：声明 `SupportsStreaming()`；分片通过 `Write` 发送，结束时调用 `Finalize`，可选通过 `Partial` 返回临时文本。
- 安全边界：短期票据绑定用户、会话和用途；分片、时长、空闲时间和单片大小受服务端限制。
- 数据策略：部分转写只用于即时显示；批量降级音频只存在于请求生命周期，不创建附件或对象存储记录。

## TTS

- 协议：OpenAI-compatible `POST /v1/audio/speech`，返回可流式读取的音频响应。
- 必需输入：最终且已授权的回答文本、模型名称；语言、音色、语速和格式按 `SynthesizeOptions` 校验。
- 支持格式：`mp3`、`wav`、`opus`、`pcm`（以实际模型能力为准）。
- 播放控制：前端必须支持加载、播放、暂停、停止、重播；开始新录音或新消息时取消未完成合成。
- 数据策略：默认不写入消息、附件、缓存或对象存储；若启用保留，必须配置允许角色、用户提示和不超过 24 小时的期限。

## 私有化验收复用

私有模型应通过同一模型配置和共享 transport 接入，记录协议、端点位置、模型身份、能力清单、延迟和失败原因。验收至少覆盖：批量 ASR、流式 ASR（若声明）、TTS 合成、取消/超时、无公网出口和默认不持久化音频；不支持实时 ASR 时应明确报告临时批量回退。
