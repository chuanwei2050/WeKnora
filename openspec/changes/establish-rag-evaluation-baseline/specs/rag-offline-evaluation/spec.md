## ADDED Requirements

### Requirement: 离线评测必须可复现且分层
系统 MUST 提供版本化案例、固定配置快照和可重复执行入口，并 MUST 按问题与来源切片报告结果。

#### Scenario: 重复执行同一基线
- **WHEN** 使用相同代码、数据、配置和固定依赖执行评测
- **THEN** 确定性指标一致，非确定性判定保留原始输出以供审计

### Requirement: 评测必须同时衡量质量与成本
报告 MUST 包含 Recall@K、MRR 或 nDCG、无答案准确率、引用正确性、回答正确性、延迟、Token 和外部调用次数。
nDCG 的理想排序分母 MUST 基于相关证据与 K，不得随实际返回长度缩小；来源置换指标 MUST 将缺失排名计为置换。

#### Scenario: 比较候选配置
- **WHEN** 候选策略提高召回但增加调用和延迟
- **THEN** 报告同时展示质量增益与成本变化，不得只给单一总分
