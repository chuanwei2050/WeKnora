## Context

线上策略包含查询扩展、来源先验和多类阈值，单看答案示例无法隔离各策略的收益与成本。

## Goals / Non-Goals

**Goals:** 提供可复现、分层、包含质量与成本指标的离线基线，并支持配置对比。

**Non-Goals:** 不把主观评测包装成绝对真值，不在本变更中直接调整线上参数。

## Decisions

- 数据按问题类型、答案可得性、来源类型、语言和范围类型分层，案例携带期望证据。
- 检索层计算 Recall@K、MRR/nDCG；端到端计算无答案、引用和回答正确性；同时记录延迟、Token 与调用次数。
- 基线文件版本化，评测报告包含配置快照和随机性控制信息。

## Risks / Trade-offs

- [Risk] 数据集过拟合 → 保留独立验收集并按切片报告。
- [Risk] LLM judge 不稳定 → 优先确定性指标，judge 固定模型/提示并保存原始判定。
