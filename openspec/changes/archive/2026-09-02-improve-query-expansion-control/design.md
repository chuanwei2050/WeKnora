## Context

当前扩展触发主要依赖召回数量；中文字符判断分支与 Unicode 字母判断重叠，但简单改成逐字切分会降低检索质量。

## Goals / Non-Goals

**Goals:** 用质量与预算共同决定扩展，限制放大，并与关键词索引分词语义对齐。

**Non-Goals:** 不自建新的中文分词器，不在缺少基线时拍脑袋改变默认权重。

## Decisions

- 触发信号组合顶部得分、分数间隔、有效候选数和无答案风险，而非仅检查数量。
- 复用关键词检索的查询分析/分词接口；不可用时保留原查询而不是逐字符扩展。
- 扩展变体、额外检索调用和合并候选共享请求预算。

## Risks / Trade-offs

- [Risk] 质量信号尺度跨模型不一致 → 使用归一化信号并按模型配置评测。
- [Risk] 收紧预算损失长尾召回 → 用分层离线数据和灰度指标验证。
