## ADDED Requirements

### Requirement: 平台管理员必须能够管理租户生命周期
系统 MUST 仅允许平台管理员列出、新增、编辑、启用、停用和软删除租户，并 MUST 拒绝租户管理员和普通成员调用平台租户管理操作。

#### Scenario: 平台管理员创建租户
- **WHEN** 平台管理员提交合法的租户名称、说明和配额
- **THEN** 系统创建状态为 `active` 的租户并在租户列表中返回

#### Scenario: 非平台管理员管理租户
- **WHEN** 租户管理员或普通成员调用平台租户新增、编辑、停用或删除接口
- **THEN** 系统返回禁止访问且不修改任何租户数据

### Requirement: 停用和删除租户必须阻断访问且保留数据一致性
系统 MUST 在租户状态为 `suspended` 或租户已软删除时拒绝该租户用户访问业务 API；删除租户 MUST 使用软删除且 MUST NOT 级联删除知识、文件或用户。

#### Scenario: 停用租户后访问
- **WHEN** 平台管理员停用租户且该租户已有用户继续请求业务 API
- **THEN** 系统拒绝请求，租户数据保持不变并可在重新启用后继续使用

#### Scenario: 删除租户
- **WHEN** 平台管理员确认删除非当前管理租户
- **THEN** 系统软删除租户、阻断其用户访问且不物理删除关联业务数据

### Requirement: 管理员必须能够管理租户内用户
系统 MUST 允许平台管理员管理任意租户用户，并 MUST 允许租户管理员列出、创建、统一编辑和启用或禁用本租户用户。统一编辑 MUST 支持修改用户名、可选重置密码、修改普通成员角色及配置知识库可见范围。

#### Scenario: 租户管理员创建普通成员
- **WHEN** 租户管理员在本租户提交唯一用户名、符合强度的初始密码和知识库范围
- **THEN** 系统创建 `member` 用户、保存所选知识库范围且不创建新租户

#### Scenario: 平台管理员创建租户管理员
- **WHEN** 平台管理员在目标租户创建角色为 `tenant_admin` 的用户
- **THEN** 系统将用户归属目标租户并授予租户管理权限

#### Scenario: 管理员编辑普通成员
- **WHEN** 管理员在编辑弹窗修改普通成员的用户名、密码、角色或知识库范围
- **THEN** 系统校验后保存全部变更，密码留空时保持原密码不变

### Requirement: 用户管理必须强制租户隔离和角色上限
系统 MUST 拒绝租户管理员读取或修改其他租户用户，MUST 拒绝租户管理员创建或授予 `platform_admin`，MUST 拒绝修改现有 `tenant_admin` 或 `platform_admin` 的角色，并 MUST 拒绝普通成员访问用户管理 API。

#### Scenario: 跨租户修改用户
- **WHEN** 租户管理员尝试修改路径中其他租户的用户
- **THEN** 系统返回禁止访问且目标用户保持不变

#### Scenario: 租户管理员提升平台管理员
- **WHEN** 租户管理员尝试将用户角色设置为 `platform_admin`
- **THEN** 系统拒绝请求且不改变用户角色

#### Scenario: 修改管理员角色
- **WHEN** 管理员尝试修改现有租户管理员或平台管理员的角色
- **THEN** 系统拒绝请求且目标管理员角色保持不变

### Requirement: 普通成员知识库可见范围必须可配置且不可绕过
系统 MUST 让普通成员默认查看本租户当前及未来的全部知识库，并 MUST 允许管理员改为指定知识库集合。系统 MUST 在知识库列表、详情、检索和问答边界执行该范围；租户管理员和平台管理员 MUST 始终可访问全部知识库。

#### Scenario: 新建普通成员使用默认范围
- **WHEN** 管理员创建普通成员且未指定知识库范围
- **THEN** 用户可查看租户全部现有知识库，并自动获得以后新建知识库的查看权限

#### Scenario: 普通成员使用指定范围
- **WHEN** 管理员将普通成员知识库范围改为 `selected` 并选择若干知识库
- **THEN** 用户列表和检索仅返回所选知识库，直接请求未选知识库 ID 时返回禁止访问

#### Scenario: 提交其他租户知识库
- **WHEN** 管理员为用户提交不属于目标租户的知识库 ID
- **THEN** 系统拒绝请求且原知识库范围保持不变

### Requirement: 仅没有文档操作记录的普通成员可删除
系统 MUST 仅允许管理员删除普通成员，并 MUST 在用户创建过知识库、文档或知识版本，或执行过版本审核时拒绝删除。成功删除 MUST 使用软删除并撤销目标用户全部令牌。

#### Scenario: 删除未操作文档的普通成员
- **WHEN** 管理员删除没有任何文档操作引用的普通成员
- **THEN** 系统软删除用户、撤销其令牌并从用户列表移除

#### Scenario: 删除有文档操作记录的用户
- **WHEN** 管理员删除被知识库、知识、知识版本或版本审核记录引用的用户
- **THEN** 系统返回冲突且用户保持不变

#### Scenario: 删除管理员或当前用户
- **WHEN** 管理员尝试删除租户管理员、平台管理员或当前登录用户
- **THEN** 系统拒绝请求且目标用户保持不变

#### Scenario: 删除资格暂时无法计算
- **WHEN** 用户列表加载时某个用户的删除资格查询失败
- **THEN** 系统仍返回用户列表并将该用户的删除操作保守标记为不可用

### Requirement: 账号安全变更必须撤销现有会话
系统 MUST 在用户被禁用、密码被管理员重置、角色被调整或用户被删除后撤销该用户全部现有令牌，并 MUST 在用户或租户停用时拒绝新登录。

#### Scenario: 管理员重置密码
- **WHEN** 管理员为有权限管理的用户设置符合强度的新密码
- **THEN** 旧密码和现有令牌失效，新密码可用于重新登录

#### Scenario: 禁用用户
- **WHEN** 管理员禁用目标用户
- **THEN** 目标用户的现有令牌失效且不能再次登录，直到被重新启用

### Requirement: 租户必须保留至少一个可用租户管理员
系统 MUST 拒绝禁用或降级租户最后一个处于启用状态的租户管理员。

#### Scenario: 禁用最后一个租户管理员
- **WHEN** 管理员尝试禁用租户内唯一启用的 `tenant_admin`
- **THEN** 系统返回冲突响应且用户状态保持启用

### Requirement: 管理页面必须按角色提供对应操作
系统 MUST 为平台管理员提供租户管理页面，并 MUST 为平台管理员和租户管理员提供用户管理页面；新增与编辑用户弹窗 MUST 使用一致的角色、密码和知识库范围控件且输入控件 MUST 占满表单可用宽度；用户列表 MUST 通过统一编辑弹窗修改用户，操作栏 MUST 提供符合删除条件时可用的删除操作；普通成员 MUST 看不到入口且直接访问路由时被拒绝。

#### Scenario: 平台管理员访问管理页面
- **WHEN** 平台管理员登录并打开平台管理导航
- **THEN** 系统显示租户管理和用户管理入口及其授权操作

#### Scenario: 普通成员直接访问管理路由
- **WHEN** 普通成员输入租户或用户管理页面 URL
- **THEN** 前端拒绝进入且后端管理 API 同样返回禁止访问
