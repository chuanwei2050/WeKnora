## ADDED Requirements

### Requirement: 复杂 Office 文档使用异步预览
系统 MUST 以100 MiB为DOCX即时预览边界，并结合声明解压量、压缩条目数和压缩比执行安全检查；超过100 MiB时 MUST 创建或复用前30页后台预览任务，而不得在浏览器中尝试整份原始排版。

#### Scenario: 小文档即时预览
- **WHEN** DOCX 原文件不超过100 MiB且未触发ZIP安全拒绝条件
- **THEN** 系统允许沿用浏览器即时预览

#### Scenario: 复杂文档转入后台
- **WHEN** DOCX原文件超过100MiB但未触发恶意文件硬限制
- **THEN** 前端提交前30页后台预览任务并展示可查询的处理状态，不在主线程执行完整排版

#### Scenario: 可疑压缩包拒绝转换
- **WHEN** Office 压缩包使用不受支持的 ZIP64、目录损坏或压缩比超过 100
- **THEN** 系统拒绝即时和异步排版，返回稳定错误码并提供已解析文本降级

### Requirement: 预览任务持久化、去重且可取消
系统 SHALL 使用租户、知识 ID 和内容版本唯一标识预览任务，并持久化任务状态，使 API 多实例、页面刷新和 Worker 重启不会创建重复转换。

#### Scenario: 重复请求复用任务
- **WHEN** 同一租户对同一文档内容版本重复创建预览任务
- **THEN** 系统返回已有的进行中或已完成任务，而不重复入队

#### Scenario: 文档版本变化
- **WHEN** 文档内容版本在旧预览任务执行期间发生变化
- **THEN** 旧任务产物不得作为新版本预览返回，且新版本可创建独立任务

#### Scenario: 取消等待中的任务
- **WHEN** 有权限的用户取消处于 queued 状态的任务
- **THEN** 系统撤销任务并将状态设置为 cancelled

### Requirement: 转换工作受到硬资源限制
系统 MUST 在独立 Worker 子进程中执行Office前30页转PDF。普通异步任务 MUST 强制执行300秒超时、200MiB输出上限和30页上限；原文件超过256MiB的任务 MUST 使用独立单并发队列，并强制执行1GiB输入、4GiB声明解压量、50000个压缩条目、900秒、256MiB输出和30页上限，以及部署环境配置的CPU和4–6GiB内存限制。

#### Scenario: 转换超时
- **WHEN** 转换子进程超过 300 秒仍未完成
- **THEN** Worker 终止子进程、清理临时文件并将任务标记为 failed，错误码为 `conversion_timeout`

#### Scenario: 输出超过硬上限
- **WHEN** 转换产物超过 200 MiB 或 2000 页
- **THEN** Worker 删除产物并将任务标记为 failed，不将超限内容写入对象存储

#### Scenario: 约五百 MiB 的超大 DOCX
- **WHEN** DOCX原文件超过256MiB但不超过1GiB且未触发可疑压缩包拒绝条件
- **THEN** 系统将前30页任务送入超大文档单并发队列，并应用900秒、256MiB PDF和30页硬限制

#### Scenario: 超大文档超过硬上限
- **WHEN** 超大文档超过 1 GiB 输入、4 GiB 声明解压量、50000 个压缩条目、900 秒、500 MiB PDF 或 5000 页中的任一限制
- **THEN** Worker 终止或拒绝任务、清理临时内容并返回对应稳定错误码

#### Scenario: 转换器不可用
- **WHEN** Worker 环境中缺少可执行的 LibreOffice Writer
- **THEN** 任务失败并返回 `converter_unavailable`，前端继续提供文本降级

### Requirement: 预览产物按文档权限安全读取
系统 MUST 将成功产物保存到知识库对应的对象存储，并在创建、查询、取消和读取产物时校验当前租户及知识库 Viewer 权限。

#### Scenario: 授权用户读取 PDF
- **WHEN** 当前内容版本的预览任务成功且用户具有知识库 Viewer 权限
- **THEN** 系统以 `application/pdf` 流式返回产物并支持按范围读取

#### Scenario: 越权读取被拒绝
- **WHEN** 用户仅持有 task ID 或产物路径但不具有目标知识库权限
- **THEN** 系统拒绝查询和读取，且不泄露产物是否存在

#### Scenario: 产物过期
- **WHEN** 预览状态或产物超过配置的 TTL
- **THEN** 系统不再返回旧产物，并允许创建新的预览任务

### Requirement: 前端提供非阻塞进度与降级体验
前端 SHALL 轮询异步任务状态并在成功后展示 PDF；等待、失败、取消或过期期间 MUST 保持页面可交互，并提供已解析文本、分块和原文件下载入口。

#### Scenario: 后台转换进行中
- **WHEN** 任务处于 queued 或 running
- **THEN** 页面显示阶段和进度，用户可以关闭详情页且任务继续在后台执行

#### Scenario: 部分预览转换成功
- **WHEN** 任务状态变为 succeeded
- **THEN** 前端停止轮询并加载当前内容版本对应的前30页PDF，同时提示下载原文件查看完整内容

#### Scenario: 转换失败
- **WHEN** 任务状态变为 failed、cancelled 或 expired
- **THEN** 前端停止轮询、显示可理解的失败原因，并保留重试和完整文本入口

### Requirement: 大文件下载不受普通 API 短超时影响
前端 MUST 不对原文件下载应用普通 API 的 30 秒超时；超过 256 MiB 的文件 MUST 使用经授权的对象存储签名 URL 或不经过前端 Blob 的流式下载，同时 SHALL 保留服务端权限、存储和网关错误处理。

#### Scenario: 下载超过三十秒
- **WHEN** 合法原文件下载耗时超过 30 秒且服务端连接仍正常
- **THEN** 前端继续接收文件而不主动中断请求

#### Scenario: 下载服务端失败
- **WHEN** 服务端因权限、源文件不存在或存储错误拒绝下载
- **THEN** 前端显示服务端提供的可用错误信息，否则显示通用下载失败提示

#### Scenario: 超大文件直接下载
- **WHEN** 用户下载超过 256 MiB 的原文件
- **THEN** 浏览器直接保存签名 URL 或流式响应，前端 JavaScript 不得先把完整文件加载为 Blob

### Requirement: 超大文件上传使用可恢复传输
系统 MUST 对超过 256 MiB 的文件使用对象存储分片上传或等价的可恢复传输，并在完成后由服务端校验大小、哈希、租户和目标知识库再创建知识条目。

#### Scenario: 超大文件上传成功
- **WHEN** 用户上传超过 256 MiB 且不超过 1 GiB 的支持文件
- **THEN** 前端使用分片或签名直传并显示进度，API 进程和 Nginx 不缓存完整文件内容

#### Scenario: 上传中断后恢复
- **WHEN** 超大文件上传过程中网络中断且上传会话未过期
- **THEN** 用户可从已完成分片继续上传，而无需重新传输整个文件

#### Scenario: 完成回调校验失败
- **WHEN** 分片完成后的文件大小、哈希、租户或知识库权限校验失败
- **THEN** 系统拒绝创建知识条目并安排清理未引用对象

### Requirement: 超大文件解析与普通任务隔离
系统 MUST 将超过 256 MiB 的文档解析任务送入独立单并发队列，并为其设置 30 分钟执行超时、1 GiB 输入上限、临时磁盘与内存限制；普通文档队列不得被超大任务占满。

#### Scenario: 超大文档进入隔离队列
- **WHEN** 已完成上传的文档超过 256 MiB 但不超过 1 GiB
- **THEN** 系统将解析任务送入超大文档单并发队列并持久化独立进度

#### Scenario: 超大解析任务超时或超限
- **WHEN** 解析超过 30 分钟或突破配置的内存、临时磁盘或输入上限
- **THEN** Worker 终止任务并记录稳定错误码，不影响普通解析队列继续消费
