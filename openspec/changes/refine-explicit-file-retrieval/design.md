## Context

显式文件选择既表示访问范围，也可能表示全文阅读意图；现有小文件 DirectLoad 将两者混为一谈。

## Goals / Non-Goals

**Goals:** 默认在文件范围检索，仅对明确全文意图或索引故障使用有界全文上下文。

**Non-Goals:** 不改变权限模型，不承诺任意大文件全文装入上下文。

## Decisions

- 文件 ID 始终作为检索过滤条件，而非相关性满分信号。
- 全文意图由现有意图理解结果中的显式信号触发；没有可靠信号时默认检索。
- DirectLoad 降级受统一候选/Token 上限约束并携带原因。

## Risks / Trade-offs

- [Risk] 用户只说“总结这个文件”时漏判全文意图 → 为常见全文任务建立定向测试。
- [Risk] 索引未就绪时无答案 → 保留有界 DirectLoad 降级。
