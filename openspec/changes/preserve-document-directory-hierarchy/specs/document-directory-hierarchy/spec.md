## ADDED Requirements

### Requirement: 文件夹上传保留文档目录
系统 SHALL 将文件夹上传中的相对目录解析为当前知识分类所属的独立目录实体层级，并把每个文档关联到其直属目录；文档文件名、物理存储路径与目录关联 MUST 保持独立，普通上传和未携带目录的旧客户端 SHALL 将文档创建在其知识分类的文档目录根级。

#### Scenario: 上传多层文件夹
- **WHEN** 用户选择包含 `项目/规范/标准.pdf` 的文件夹并上传
- **THEN** 系统将文档文件名保存为 `标准.pdf`
- **AND** 创建或复用 `项目` 与其子目录 `规范` 并将文档关联到 `规范`
- **AND** 文档仍继承当前选中的左侧知识分类

#### Scenario: 上传根级单文件
- **WHEN** 客户端上传文件且未提供文档目录
- **THEN** 系统将该文档保存到文档目录根级
- **AND** 现有上传客户端无需修改即可继续工作

#### Scenario: 在当前目录上传
- **WHEN** 新版客户端在根级或子目录上传单个文件或文件夹
- **THEN** 单文件关联当前 `directory_id`
- **AND** 文件夹的 `directory_path` 相对于当前 `parent_directory_id` 建树
- **AND** 目录及文档的 `tag_id` 与当前知识分类一致
- **AND** 服务端在同一写事务中锁定并复查祖先删除状态

#### Scenario: 拒绝跨分类目录关联
- **WHEN** 客户端提交的 `directory_id` 或 `parent_directory_id` 不属于当前 `tag_id`
- **THEN** 系统拒绝请求且不创建目录、文档或部分关联

#### Scenario: 部分上传留下空目录
- **WHEN** 系统已按上传路径创建目录但其文件随后因重复或失败而未创建
- **THEN** 系统保留该合法空目录
- **AND** 用户可以在右侧删除该空目录

#### Scenario: 拒绝危险目录路径
- **WHEN** 客户端提交绝对路径、盘符路径、`.`、`..`、NUL 或超过长度/深度限制的目录
- **THEN** 系统返回参数错误且不创建文档记录或保存上传文件

#### Scenario: 相同内容位于不同目录
- **WHEN** 文件夹上传中的文件内容与同一知识库已有文档相同但目录不同
- **THEN** 系统继续按现有文件哈希规则将其识别为重复文档
- **AND** 不因目录不同创建第二份知识记录
- **AND** 不移动已有文档，并在上传结果中返回已有文档及其当前 `directory_breadcrumb`

### Requirement: 右侧文档区按目录逐级浏览
系统 SHALL 在右侧文档区域展示当前目录的直属子目录和直属文档，并提供从文档目录根级到当前目录的面包屑；目录具有稳定 ID 和独立生命周期。

#### Scenario: 查看文档目录根级
- **WHEN** 新版目录界面以当前 `tag_id` 显式请求文档目录根级
- **THEN** 系统只展示该知识分类的根级直属目录和根级直属文档
- **AND** 不把子目录中的文档平铺在根级

#### Scenario: 切换知识分类
- **WHEN** 用户从一个左侧知识分类切换到另一个知识分类
- **THEN** 系统清除当前目录和面包屑并加载目标分类的文档目录根级
- **AND** 原分类创建的空目录或非空目录均不出现在目标分类

#### Scenario: 兼容旧列表调用
- **WHEN** 客户端调用现有知识列表接口且未提供 `directory_id`
- **THEN** 系统继续按既有语义返回知识库范围内的平铺文档
- **AND** 不因文档位于子目录而将其排除

#### Scenario: 进入子目录
- **WHEN** 用户点击右侧目录项
- **THEN** 系统展示该目录的直属子目录和直属文档
- **AND** 面包屑显示完整层级并允许返回任一祖先目录

#### Scenario: 网格和列表视图一致
- **WHEN** 用户在网格视图与列表视图之间切换
- **THEN** 两种视图展示相同的当前目录、直属目录和直属文档集合

#### Scenario: 删除目录内最后一个文档
- **WHEN** 某目录中的最后一个文档被删除
- **THEN** 该目录仍作为空目录显示

#### Scenario: 存量文档展示
- **WHEN** 用户查看升级前不存在目录信息的文档
- **THEN** 系统在文档目录根级展示该文档

### Requirement: 管理右侧文档目录
系统 SHALL 复用现有同类文档操作权限：文件上传沿用投稿权限；新建、重命名和移动目录仅允许现有文档编辑权限；删除目录沿用现有批量文档删除权限；本变更不得重新定义既有角色边界。

#### Scenario: 投稿用户只能上传文件
- **WHEN** 仅具备投稿权限的用户查看右侧文档目录
- **THEN** 用户可以上传单个文件到当前目录
- **AND** 用户不可上传文件夹，也不可新建、重命名、移动或拖拽目录及删除目录
- **AND** 服务端拒绝该用户携带 `parent_directory_id` 或 `directory_path` 的文件夹上传请求，但允许单文件携带已有 `directory_id` 上传到当前目录
- **AND** 服务端对目录管理和文档/目录移动请求执行同样的权限校验

#### Scenario: 新建根级或子目录
- **WHEN** 管理员在文档目录根级或任一现有目录中提交有效且同级不重名的名称
- **THEN** 系统创建直属目录并立即显示
- **AND** 新建目录即使没有文档也保持存在

#### Scenario: 重命名目录
- **WHEN** 管理员将目录改为有效且同级不重名的名称
- **THEN** 系统只更新该目录名称
- **AND** 子目录和文档关联保持不变
- **AND** 不触发文档重新解析、重建索引或治理版本变化

#### Scenario: 拒绝同级重名
- **WHEN** 管理员新建或重命名后的名称经过 Unicode NFC、首尾空白移除和 Unicode case folding 后与同一父目录的现有目录重名
- **THEN** 系统返回冲突且不改变目录树

#### Scenario: 不同分类允许同名根目录
- **WHEN** 两个知识分类分别创建规范化名称相同的根目录
- **THEN** 系统分别创建成功且两棵目录树互不可见

#### Scenario: 删除空目录
- **WHEN** 知识库管理员删除没有直属文档且没有直属子目录的目录并确认操作
- **THEN** 系统删除该目录并返回其父目录视图

#### Scenario: 删除非空目录
- **WHEN** 知识库管理员删除含文档或子目录的目录
- **THEN** 系统先返回完整子树的目录数、文档数和总存储大小供用户确认
- **AND** 预检返回绑定操作者、目录和当前子树快照且具有有效期的 `confirmation_token`
- **AND** 用户携带有效 Token 确认后，系统重新校验当前权限并原子消费 Token
- **AND** 系统按现有批量上限将文档分为不超过 200 条的异步删除任务，递归删除整棵目录及其中全部文档
- **AND** 每个分片复用现有可幂等重试的批量文档删除流程
- **AND** 所有文档清理成功后系统按从叶到根的顺序删除目录记录

#### Scenario: 确认后子树发生变化
- **WHEN** 删除确认 Token 已过期，或目录、文档集合及更新时间与预检快照不同
- **THEN** 系统返回 `409 directory_changed` 且不开始删除
- **AND** 用户必须重新获取影响范围并确认

#### Scenario: 预检后权限被撤销或 Token 被重放
- **WHEN** 操作者在预检后失去批量删除权限，或重复提交已消费的 Token
- **THEN** 系统拒绝删除且不改变目录或文档
- **AND** Token 不替代正式执行时的当前权限校验

#### Scenario: 取消删除非空目录
- **WHEN** 用户查看递归删除影响范围后取消确认
- **THEN** 系统不创建删除任务且不改变任何目录或文档

#### Scenario: 删除期间阻止目录变更
- **WHEN** 目录子树的递归删除任务正在运行
- **THEN** 系统将该子树标记为删除中
- **AND** 拒绝向该子树上传文档、新建或改名目录以及重复提交删除
- **AND** 所有子树写操作通过与删除确认一致的祖先锁顺序防止检查与提交之间的竞态

#### Scenario: 服务重启后恢复删除
- **WHEN** 目录递归删除任务执行期间服务重启或队列消息被再次投递
- **THEN** 系统补投持久化的待投递分片，或按稳定任务 ID 幂等继续原任务
- **AND** 不重复扣减存储配额或重复清理已完成文档

#### Scenario: 递归删除分片失败
- **WHEN** 目录删除任务中的某个分片清理失败
- **THEN** 系统保留失败分片中的文档及承载它们所需的目录
- **AND** 不恢复已经成功的分片
- **AND** 子树保持锁定，任务返回失败分片摘要并由现有 worker 整片幂等重试
- **AND** 任务确认后不支持取消、恢复可检索状态或人工解锁

#### Scenario: 拒绝跨作用域删除任务
- **WHEN** 删除任务携带的协调记录、租户、知识库、文档或任务 ID 不一致
- **THEN** worker 拒绝执行整个分片并记录安全错误
- **AND** 不删除或泄露任何其他租户或知识库的文档

#### Scenario: 软删除文档后删除目录
- **WHEN** 目录文档的外部资源已经清理成功
- **THEN** 系统在同一数据库事务中清空这些文档的目录关联并执行软删除
- **AND** 仅在没有任何文档引用后删除对应目录记录

#### Scenario: 拒绝无权限管理
- **WHEN** 用户不具备对应投稿、文档编辑或批量删除权限却尝试相关目录操作
- **THEN** 系统返回无权限且目录树保持不变

#### Scenario: 拒绝非法名称
- **WHEN** 客户端提交空名称、`.`、`..`、路径分隔符、NUL 或超长名称
- **THEN** 系统返回参数错误且目录树保持不变

### Requirement: 拖拽移动文档和目录
系统 SHALL 允许具备现有文档整理权限的用户把文档或目录拖入目标目录或根级；拖拽 MUST 只改变父级归属，不改变排序、文档身份或检索内容。

#### Scenario: 把文档拖入目录
- **WHEN** 管理员把一个或多个文档拖到同一知识库的目标目录
- **THEN** 系统原子更新文档的 `directory_id`
- **AND** `knowledge_id`、Chunk、索引、治理版本和历史引用保持不变

#### Scenario: 把目录拖入另一目录
- **WHEN** 管理员把目录拖到同一知识库的另一目录
- **THEN** 系统原子更新源目录的父级且保留整棵子树
- **AND** 不触发子树文档重解析或重建索引

#### Scenario: 拖到根级或面包屑祖先
- **WHEN** 管理员把文档或目录拖到根级或面包屑中的祖先目录
- **THEN** 系统将其移动到该放置目标并刷新当前视图
- **AND** 当前目录面包屑位于顶部文件类型筛选控件之后

#### Scenario: 勾选后移动到文档目录
- **WHEN** 用户在当前知识分类勾选一个或多个文档或目录并点击批量操作栏的“移动到文档目录”
- **THEN** 系统显示当前知识分类内的目录树和根级作为目标
- **AND** 通过与拖放相同的移动 API 原子移动所选条目
- **AND** 不提供剪切、粘贴、CutSet 或跨页面暂存状态

#### Scenario: 批量栏按选择类型提供操作
- **WHEN** 用户勾选右侧条目
- **THEN** 纯目录选择提供移至目录、移至分类、下载和删除，单个目录额外提供重命名
- **AND** 纯文档选择沿用已有适用操作，并提供“移动到文档目录”和“移至分类”
- **AND** 混合选择只提供“移动到文档目录”，不提供删除或移至分类

#### Scenario: 单项操作与当前页多选
- **WHEN** 用户在列表或网格查看单个目录
- **THEN** 该目录的单项操作入口提供“移至目录”、下载、重命名和删除
- **AND** 单个文档完整保留其已有的重建、移动、删除及治理操作，并在旁边新增短文案“移至目录”的同分类目录移动入口
- **AND** 单项、弹窗和批量入口统一将目录归属操作显示为“移至目录”，将知识分类调整操作显示为“移至分类”
- **WHEN** 用户点击列表表头全选
- **THEN** 系统同时选中当前页全部有权限操作的文档和目录
- **AND** 用户仍可逐项勾选或取消勾选以形成文件、目录或混合多选集合
- **AND** 批量栏只展示对当前选择整体有效的操作，单项专属操作不得伪装成批量能力

#### Scenario: 不新增页面右键菜单
- **WHEN** 用户在右侧内容区、目录或文档上点击右键
- **THEN** 系统保留浏览器默认右键行为
- **AND** 本变更的任何功能均不依赖右键、`Ctrl+X` 或 `Ctrl+V`

#### Scenario: 保留无需勾选的普通入口
- **WHEN** 用户未勾选任何条目
- **THEN** 顶部工具栏继续提供新建目录、上传文件和上传文件夹

#### Scenario: 突出新建文件夹入口
- **WHEN** 用户具有新建文档目录权限并查看右侧文档区
- **THEN** 顶部右侧操作区在添加文档入口左侧显示“新建文件夹”文字按钮
- **AND** “添加文档”也显示为文字按钮并保留原下拉菜单
- **AND** 两个按钮使用现有品牌主色背景和高对比白色文字、保持同高，并与搜索、筛选和视图切换控件垂直居中
- **AND** 目录可直接打开，文档可直接预览

#### Scenario: 移动集合包含祖先和后代
- **WHEN** 多选集合同时包含某目录及其后代条目
- **THEN** 系统只保留最外层选中目录作为移动源
- **AND** 后代随目录子树移动且不会被重复处理

#### Scenario: 移动到原父级
- **WHEN** 用户将全部所选条目移动到其原父级
- **THEN** 系统将操作视为无变化并清除当前选择

#### Scenario: 拒绝目录环
- **WHEN** 用户把目录拖入自身或任一子孙目录
- **THEN** 系统拒绝移动且目录树保持不变

#### Scenario: 拒绝无效移动
- **WHEN** 同分类移动源或目标跨知识库、正在删除、无编辑权限，或目标存在规范化同名目录
- **THEN** 系统拒绝整次移动且不产生部分成功

#### Scenario: 调整文档知识分类后回到根级
- **WHEN** 用户勾选纯文档集合并通过批量操作栏的“调整知识分类”把目录内文档调整到另一知识分类
- **THEN** 系统在同一事务中更新 `tag_id` 并清空 `directory_id`
- **AND** 文档身份、Chunk、索引和引用保持不变

#### Scenario: 目录跨知识分类移动
- **WHEN** 用户对单个目录或纯目录多选集合执行“移至分类”并选择另一知识分类
- **THEN** 系统将每个最外层选中目录提升为目标分类根级
- **AND** 子目录层级、文档 `directory_id`、文档身份和原始文件名保持不变
- **AND** 同一事务内更新目录和文档 `tag_id`，提交后最多重试三次同步所有受影响 Chunk 标签与检索索引
- **AND** 若检索索引暂时不可用，系统记录同步失败并保持已提交的目录移动结果，不将已提交操作报告为失败
- **AND** 目标分类根级存在规范化同名目录时整次操作失败且不产生部分成功

#### Scenario: 目录分类操作仅适用于纯目录选择
- **WHEN** 批量选择同时包含文档和目录
- **THEN** 批量操作栏不提供“移至分类”
- **AND** 用户仍可在当前分类内使用“移动到文档目录”

#### Scenario: 拖拽不改变排序
- **WHEN** 用户把条目放到列表空白处、行间位置或同一父目录
- **THEN** 系统不保存自定义顺序
- **AND** 列表继续由当前 `sort_by` 与 `sort_order` 决定

### Requirement: 分类限定目录空间并可组合搜索和类型筛选
系统 MUST 将左侧知识分类与右侧文档目录作为不同实体；每棵目录树必须由 `tag_id` 限定并只在所属分类下显示。分类继续使用 `tag_id` 及其既有子分类语义决定检索范围，文档目录不得成为检索条件或改变权限。

#### Scenario: 在分类中浏览目录
- **WHEN** 用户选中左侧知识分类并进入右侧文档目录
- **THEN** 系统展示当前分类、当前目录的全部直属目录和直属文档，包括空目录
- **AND** 不展示其他分类的任何右侧目录
- **AND** 切换分类不会创建、删除或修改原分类的目录

#### Scenario: 展示目录计数
- **WHEN** 用户查看右侧目录项
- **THEN** 目录计数只统计当前用户可见的递归文档
- **AND** 计数限定在目录所属分类内，且不随文件类型或关键词筛选变化

#### Scenario: 在当前目录按类型筛选
- **WHEN** 用户在逐级浏览模式选择文件类型
- **THEN** 系统只过滤当前目录的直属文档
- **AND** 直属目录保持显示并可继续导航

#### Scenario: 在当前目录搜索
- **WHEN** 用户在某个文档目录提交关键词
- **THEN** 系统在当前分类范围与该目录完整子树的交集中搜索文档
- **AND** 以扁平结果展示匹配文档及其目录位置，不展示目录项
- **AND** 目录位置使用只读 `directory_breadcrumb` 的稳定 ID 与名称数组表示，根级为空

#### Scenario: 清除目录搜索
- **WHEN** 用户清除关键词
- **THEN** 系统恢复当前目录的逐级展示与文档分页

#### Scenario: 治理可见性先于统计和分页
- **WHEN** 普通读取者浏览、搜索或统计启用治理的知识库
- **THEN** 系统在目录计数、结果总数和分页之前排除该用户不可见的文档
- **AND** 不通过计数、分页空洞或结果元数据泄露不可见文档

#### Scenario: 目录元数据在所属分类内可见
- **WHEN** 用户具有知识库读取权限但当前分类目录中的文档均因治理规则不可见
- **THEN** 用户仍可在所属分类内看到目录名称和层级
- **AND** 系统不返回不可见文档的数量、名称、状态或其他元数据

### Requirement: 目录模式保持稳定分页与排序
系统 SHALL 在右侧目录模式将直属目录和筛选后的直属文档组成统一分页结果，沿用 `page`、`page_size` 和滚动加载；系统 MUST 提供确定性排序，并让目录与文档统一参与当前页选择，再由批量栏按选择类型提供适用操作。

#### Scenario: 首次加载目录
- **WHEN** 用户进入文档目录且直属目录与文档总数超过一页
- **THEN** 系统按当前排序返回第 1 页统一 `entries` 和目录、文档合计 `total`
- **AND** 目录固定排在文档之前并占用分页名额

#### Scenario: 滚动加载后续页
- **WHEN** 用户滚动到当前已加载条目的底部且仍有后续页
- **THEN** 前端请求下一页并追加到现有条目
- **AND** 不重复或遗漏稳定数据集中的目录和文档
- **AND** 同一页最多一个在途请求，只有当前 query generation 的成功响应才能追加并推进页码

#### Scenario: 旧分页响应晚到
- **WHEN** 用户切换目录、筛选或排序后，旧请求晚于新请求返回
- **THEN** 前端丢弃 generation 不匹配的旧响应
- **AND** 不覆盖或追加到新查询结果

#### Scenario: 旧客户端响应结构保持兼容
- **WHEN** 客户端省略 `directory_id` 且未显式传排序参数
- **THEN** 响应 envelope、字段、分页和默认排序与变更前一致

#### Scenario: 目录数量超过一页
- **WHEN** 当前层级的直属目录数量大于 `page_size`
- **THEN** 系统分页返回目录并仅在目录页耗尽后开始返回文档
- **AND** 不为展示目录而绕过分页一次返回全部目录

#### Scenario: 默认名称排序
- **WHEN** 客户端未指定排序
- **THEN** 系统先按目录、后按文档执行名称自然升序
- **AND** 使用稳定 ID 作为最终排序键
- **AND** 系统复用现有显示名排序规则并追加稳定 ID，保证每种受支持数据库内跨页结果稳定

#### Scenario: 切换通用排序
- **WHEN** 用户按名称或更新时间选择升序或降序
- **THEN** 系统分别在目录组和文档组应用该排序
- **AND** 目录仍固定显示在文档之前

#### Scenario: 按文档专属字段排序
- **WHEN** 用户按大小、类型或状态排序
- **THEN** 系统按自然名称稳定排列目录，并仅对文档应用所选字段和方向

#### Scenario: 查询条件或目录结构变化
- **WHEN** 当前目录、左侧分类、关键词、文件类型或排序发生变化，或目录被新增、改名、删除
- **THEN** 前端清除已加载条目、文档选择和页码并从第 1 页重新加载
- **AND** 不把旧条件下的分页结果与新结果混合

#### Scenario: 搜索结果分页
- **WHEN** 用户在当前目录子树执行关键词搜索
- **THEN** 系统只对扁平匹配文档分页和排序
- **AND** `total` 不包含被隐藏的目录

#### Scenario: 文档批量选择排除目录
- **WHEN** 用户执行单选、全选或批量文档操作
- **THEN** 系统只选择 `kind=document` 的条目
- **AND** 目录条目不得被发送到文档批量接口

### Requirement: 右侧目录图标区别于左侧知识分类
系统 SHALL 为右侧文档目录使用与左侧知识分类不同的图标组件和视觉样式，使用户无需依赖位置也能区分两个维度。

#### Scenario: 同时查看左右文件夹
- **WHEN** 页面同时显示左侧知识分类和右侧文档目录
- **THEN** 左侧继续使用现有蓝色实体/电脑文件夹图标
- **AND** 右侧使用中性线框目录图标且不复用左侧 `computer-folder-icon` 样式

#### Scenario: 切换网格和列表视图
- **WHEN** 用户在右侧网格与列表视图之间切换
- **THEN** 两种视图均使用相同的右侧线框目录视觉语义

#### Scenario: 无障碍识别目录
- **WHEN** 辅助技术读取右侧目录条目
- **THEN** 条目通过文本名称、`aria-label` 和可访问操作名称表达目录身份
- **AND** 不以颜色或图标作为唯一识别方式

### Requirement: 下载文档目录
系统 SHALL 允许具有知识库编辑权限的用户将任一存在的右侧目录或多个勾选目录下载为 ZIP，归档 MUST 保留目录内部的相对层级并只包含用户可读取的原始文档；普通用户不得通过目录下载接口操作文件夹。

#### Scenario: 下载嵌套目录
- **WHEN** 用户下载包含多层子目录的右侧目录
- **THEN** 系统流式返回 ZIP 文件
- **AND** ZIP 条目保留目标目录内部的相对层级和文档基本文件名

#### Scenario: 下载空目录
- **WHEN** 具有知识库编辑权限的用户下载空目录
- **THEN** 系统返回包含该空目录条目的有效 ZIP

#### Scenario: 下载所属分类的目录
- **WHEN** 用户在选中左侧知识分类时下载该分类的右侧目录
- **THEN** 系统校验目录归属于该分类并按目录子树中的全部可见文档生成 ZIP
- **AND** 不接受客户端用其他 `tag_id` 扩大或裁剪归档内容
- **AND** 在读取和统计归档文档前应用当前用户的治理可见性

#### Scenario: 批量下载多个目录
- **WHEN** 用户纯目录多选后点击批量栏的下载
- **THEN** 系统将所选最外层目录合并为一个 ZIP，每个目录以独立顶层目录保留原名称和内部层级
- **AND** 同时选中父目录及其后代时只归档父目录一次

#### Scenario: 拒绝越权或不存在的目录下载
- **WHEN** 用户无知识库编辑权限或目标目录不存在
- **THEN** 系统不返回任何文件内容
- **AND** 不通过错误差异泄露不可见目录或文档是否存在

#### Scenario: 防止归档路径穿越
- **WHEN** 系统为目录文档生成 ZIP 条目名
- **THEN** 每个条目都位于归档根级以内且不包含绝对路径或父级跳转

#### Scenario: 归档内出现同路径同名文档
- **WHEN** 目标目录中多个可见文档映射到相同 ZIP 条目名
- **THEN** 系统为后续条目追加稳定序号以保留全部文档且不覆盖已有条目

### Requirement: 文档消费链不受目录影响
系统 MUST 继续以 `knowledge_id` 标识和消费文档，目录 ID 与名称不得写入 chunk 检索范围或替代 `file_name`；复制、跨知识库移动、重建、重新解析和治理版本切换 MUST 保留等价文档目录层级。

#### Scenario: 解析并检索目录内文档
- **WHEN** 带目录的文档完成解析并参与问答检索
- **THEN** 系统使用与根级文档相同的解析、索引、召回和排序流程
- **AND** 文档目录不成为召回过滤条件或 chunk 内容的一部分

#### Scenario: 引用目录内文档
- **WHEN** 回答引用带目录的文档
- **THEN** 引用仍通过文档 ID 定位原文和下载
- **AND** 目录仅可作为辅助展示信息
- **AND** 引用详情可携带只读 `directory_id` 与 `tag_id`，导航时打开文档所属的分类和目录

#### Scenario: 普通和批量 RAG 检索目录内文档
- **WHEN** 普通 RAG 或批量 RAG 检索位于任意右侧目录的文档
- **THEN** 系统继续只用 `knowledge_base_ids`、`knowledge_ids` 和左侧知识分类范围构造检索条件
- **AND** 右侧目录不影响解析、召回、重排、去重或结果身份

#### Scenario: 拒绝把右侧目录作为左侧分类范围
- **WHEN** 集成检索 API 收到 `folder_ids`
- **THEN** 系统只通过 tag Repository 解释和校验，非法或无权 tag 返回 `invalid_folder_ids`
- **AND** 系统绝不查询右侧 directory Repository

#### Scenario: 对话显式选择目录内文档
- **WHEN** 主对话通过文档选择器或 `@` 选择位于子目录的文档
- **THEN** 旧平铺列表仍能发现该文档并提交原 `knowledge_id`
- **AND** 对话检索范围不包含 `directory_id`

#### Scenario: 悬浮聊天框检索目录内文档
- **WHEN** 悬浮聊天框按一个或多个知识库创建对话并检索
- **THEN** 位于子目录和根级的文档遵循相同召回规则
- **AND** 悬浮聊天框无需感知或选择右侧目录

#### Scenario: 目录改名后查看历史引用
- **WHEN** 用户在目录新增或改名后查看既有回答的引用详情
- **THEN** 系统继续通过原 `knowledge_id` 和 `chunk_id` 定位文档与片段
- **AND** 不改写历史消息中的引用身份

#### Scenario: 新检索排除删除中文档
- **WHEN** RAG、批量 RAG、对话、`@` 搜索或显式文档选择构造新的文档范围
- **THEN** 系统排除删除中或不可检索文档
- **AND** 详情、预览、下载和历史引用继续沿用既有文档删除语义

#### Scenario: 递归删除期间消费文档
- **WHEN** 目录子树已锁定为删除中
- **THEN** 系统在接受删除任务的同一事务中将快照内文档标记为删除中或不可检索
- **AND** 子树文档不再进入新 RAG、批量 RAG、对话检索、显式文档选择或悬浮聊天框回答
- **AND** 已生成消息及引用记录保持不变
- **AND** 删除中或删除完成后无法读取的引用统一显示既有“引用文档不可用”反馈

#### Scenario: 删除部分失败后重试
- **WHEN** 递归删除失败并保留部分文档
- **THEN** 失败文档保持删除中且不参与新检索
- **AND** 管理员只能重试失败项，不能取消任务或恢复文档

#### Scenario: 复制或移动文档
- **WHEN** 用户复制知识库或将带目录文档移动到另一知识库
- **THEN** 系统先按现有规则映射目标知识分类，再在该分类内复制或幂等创建等价目录链并关联目标文档
- **AND** 左侧分类继续按现有目标知识库规则处理

#### Scenario: 同步已有目标知识库的目录
- **WHEN** 知识库同步发现目标库已有相同 `file_hash` 的文档但其目录关联与源库不同
- **THEN** 系统映射源目录树并更新已有目标文档的目录关联
- **AND** 只删除本次同步新建且最终未引用的空目录，不删除目标库既有或用户创建的空目录

#### Scenario: 重建或治理版本切换
- **WHEN** 带目录文档被重新解析、重建或切换治理版本
- **THEN** 文档的 `directory_id` 保持不变
